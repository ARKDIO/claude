# 메모 (iCloud Notes for Android)

갤럭시에서 iCloud 메모(`https://www.icloud.com/notes/`)를 **전체 화면 앱처럼** 쓰기 위한 개인용 WebView 앱이에요.
플레이 스토어에 올리지 않고 APK를 직접 설치해서 쓰는 것을 전제로 만들었어요.

## 기능
- 주소창 없는 전체 화면 (상태바·내비게이션바 숨김, 가장자리를 스와이프하면 잠깐 표시)
- iCloud 로그인 세션 유지 (쿠키를 기기에 영구 저장하고, 앱을 내릴 때마다 디스크에 기록)
- 메모 스타일 앱 아이콘 (적응형 아이콘과 테마 아이콘 지원)
- 뒤로가기를 누르면 메모 안에서 뒤로 이동하고, 첫 화면에서는 앱이 종료되지 않고 뒤로 숨어요

## 보안 설계
| 항목 | 내용 |
|---|---|
| 앱 잠금 | 앱을 열 때, 그리고 백그라운드에서 60초 넘게 있다가 돌아올 때 **지문 또는 PIN/패턴** 인증을 요구해요 |
| 화면 잠금 필수 | 폰에 화면 잠금이 없으면 앱이 열리지 않아요 |
| 도메인 제한 | `icloud.com`, `apple.com` 같은 Apple 도메인만 앱 안에서 열려요. 다른 링크는 사용자가 직접 누른 경우에만 외부 브라우저로 열려요 |
| 통신 | HTTPS만 허용하고 SSL 오류는 무조건 차단해요. 시스템 인증서만 신뢰하기 때문에 사용자가 설치한 인증서로 통신을 가로챌 수 없어요 |
| 백업 차단 | 로그인 쿠키가 클라우드 백업이나 기기 간 전송(Smart Switch 등)으로 빠져나가지 않아요 |
| 최근 앱 미리보기 | Android 13 이상에서는 최근 앱 목록에 메모 내용이 보이지 않아요 |
| WebView 하드닝 | JS 브리지 없음, 파일 접근 차단, 혼합 콘텐츠 차단, Safe Browsing 켬, 디버깅 끔, 카메라·마이크·위치 권한 요청 자동 거부, 다운로드 차단 |
| 권한 | `INTERNET`, `USE_BIOMETRIC` 두 가지만 써요 |
| 의존성 | 외부 라이브러리 0개 (공급망 위험 최소화) |
| 서명 키 | 저장소에 커밋하지 않고 GitHub Secrets로만 주입해요 |

> 저장되는 데이터(쿠키)는 Android 앱 전용 저장소에 들어가요. 이 저장소는 기기 암호화(FBE)로 보호되고, 다른 앱은 접근할 수 없어요.

## 빌드 (GitHub Actions)
이 폴더나 워크플로 파일이 바뀌어 push되면 `.github/workflows/android-apk.yml`이 자동으로 APK를 빌드해요.
결과물은 Actions 실행 페이지의 **Artifacts**에서 내려받으면 돼요 (zip 안에 APK가 들어 있어요).

### 고정 서명 키 등록 (권장)
키가 없으면 매번 임시 키로 서명돼요. 그러면 **업데이트할 때마다 앱을 지우고 다시 설치해야 하고, 그때 로그인도 풀려요.**
아래 4개를 저장소 **Settings → Secrets and variables → Actions → New repository secret**에 등록해 주세요.

| 이름 | 값 |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | 키스토어 파일을 base64로 인코딩한 문자열 |
| `ANDROID_KEYSTORE_PASSWORD` | 키스토어 비밀번호 |
| `ANDROID_KEY_ALIAS` | 키 별칭 |
| `ANDROID_KEY_PASSWORD` | 키 비밀번호 |

직접 만들려면 이렇게 하면 돼요.
```bash
keytool -genkeypair -keystore release.jks -alias icloudnotes -keyalg RSA -keysize 4096 -validity 10000
base64 -w0 release.jks   # 출력된 값을 ANDROID_KEYSTORE_BASE64 에 붙여넣기
```
⚠️ 키스토어 파일과 비밀번호는 저장소에 절대 올리지 마세요. 잃어버리면 같은 앱으로 업데이트할 수 없어요.

## 설치 (갤럭시)
1. APK를 폰으로 옮겨요.
2. **설정 → 보안 및 개인정보 보호 → 자동 차단**이 켜져 있다면 설치할 동안만 꺼 주세요 (One UI 6 이상).
3. APK를 열고, "출처를 알 수 없는 앱 설치"를 허용해요.
4. Play 프로텍트 경고가 뜨면 "무시하고 설치"를 누르면 돼요.
5. 설치가 끝나면 **자동 차단을 다시 켜 주세요.**

## 첫 로그인 팁
- 로그인할 때 **"이 브라우저 신뢰"**를 꼭 선택해 주세요. 그래야 세션이 오래 유지돼요.
- iCloud **고급 데이터 보호**를 켜 두셨다면, 아이폰에서 **설정 → [이름] → iCloud → "웹에서 iCloud 데이터에 접근"**을 켜야 해요.
- 세션 만료는 Apple 서버가 정해요. 가끔 다시 로그인해야 할 수 있어요.

## 알려진 한계
- 인터넷 연결이 없으면 사용할 수 없어요 (웹 기반이라서요).
- 손글씨나 스캔처럼 일부 기능은 iCloud 웹에서 제한될 수 있어요.
- 아이콘은 메모 스타일로 직접 그린 것이고, 개인 용도로만 써 주세요 (배포 금지).
